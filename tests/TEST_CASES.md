# 테스트 사례 3건

실제 LG전자 공시 3건과 각 사례의 기대 결과를 정리한다. 기대 결과는 DART 웹사이트 원문을 직접 확인해 작성했으며, 실행 후 결과를 이 기대값과 대조한다.

|---|---|---|---|---|---|
| 1 | 일반 | `20251114001332` | 분기보고서 (2025.09) | 2025-11-14 | A 정기공시 |

| 3 | 애매 | `20250930800083` | 타법인주식및출자증권처분결정 (원공시) | 2025-09-30 | I 거래소공시 |

사례 2·3은 같은 사건(LG전자 인도법인 IPO 구주매출)의 원공시와 최종 정정공시다. 금액이 비어 있는 원공시와 금액이 확정된 정정공시를 비교하면 Agent가 없는 값을 지어내지 않는지, 정정 이력을 제대로 다루는지 확인할 수 있다.

관련 공시 (정정 체인): `20250930800083` 원공시 → `20251001800092` 1차 정정 → `20251014800001` 2차 정정

## 사례 1. 일반: 분기보고서 (2025.09)

**선정 이유:** 정기보고서라 재무 주요계정의 전년 동기 비교가 명확하다. 재무 ±15% 기준이 실제로 작동하는지 확인한다.

**원문 확인값 (연결, 단위 백만원, 1~3분기 누적)**

| 계정 | 2025.1~9월 | 2024.1~9월 | 변화율 | ±15% 트리거 |
|---|---|---|---|---|
| 매출액 | 65,348,728 | 64,966,707 | +0.59% | 아니오 |
| 영업이익 | 2,587,381 | 3,284,344 | −21.2% | 예 |
| 당기순이익 | 1,946,335 | 1,305,119 | +49.1% | 예 |

출처: 2025.09 분기보고서와 2024.09 분기보고서(`20241114001247`)의 "요약재무정보 > 요약연결재무정보"

**기대 결과**
- Program: 재무 트리거 2건(영업이익 감소, 당기순이익 증가), 매출액은 트리거 없음
- Agent ① FACT: 위 수치를 원문 근거와 함께 추출. 수치를 새로 계산하지 않음
- Agent ① 키워드 판별: 원문의 "중단영업 당기순손실"에서 "중단"이 걸릴 수 있음. 회계 항목명이지 신규 사업 중단 결정이 아니므로 "실제 사건 아님"으로 판단해야 함
- Agent ② 해석: 매출은 정체인데 영업이익이 줄었다는 점(수익성 하락)을 짚어야 함. 순이익 증가는 전년 중단영업손실 축소 영향일 수 있으므로 원인은 "확인 필요"로 분리
- 사람 검토: 중요도 "중간" 예상

**확인 포인트**
- [ ] 재무 비교가 누적(1~9월) 기준끼리, 또는 3개월 단독 기준끼리 비교되었는가 (섞이면 오류)
- [ ] 연결(CFS)과 별도(OFS)가 섞이지 않았는가
- [ ] Program 변화율이 위 표와 일치하는가

## 사례 2. 복잡: [기재정정] 타법인주식및출자증권처분결정 (2차 정정)

**선정 이유:** 금액·지분율·환율·공모가 범위 등 수치가 많고, 같은 사건의 이전 공시(1차 정정)와 금액을 비교해야 한다. 정정 공시를 하나의 사건으로 연결하는지도 확인한다.

**원문 확인값**

| 항목 | 값 |
|---|---|
| 발행회사 | LG ELECTRONICS INDIA LIMITED (인도, 계열회사, 가전 생산·판매) |
| 처분주식수 | 101,815,859주 |
| 처분금액 | 정정 전 1,738,485,000,000원 → 정정 후 1,856,757,000,000원 |
| 자기자본대비 | 정정 전 6.90% → 정정 후 7.36% |
| 처분 후 지분 | 576,956,533주, 85.0% |
| 처분목적 | 인도법인의 인도시장 IPO에 따른 보유 구주 매출 |
| 처분예정일 | 2025-10-13 |
| 금액 산정 기준 | 주당 공모가 상단 1,140루피, 10/13 환율 16.00원/루피 적용 |

**기대 결과**
- Program: 처분금액 비교 +6.8%(1,738,485 → 1,856,757 백만원)로 ±20% 트리거 없음. 같은 유형의 과거 사례는 2022~2025 목록에 없음. 수집 범위가 2022년부터라 5년 창(2020~)은 확인 불가 → `HISTORY_COVERAGE_INCOMPLETE`, 정정 연결이 불확실하면 `CORRECTION_LINK_UNCONFIRMED`
- Agent ① FACT: 위 표의 값을 원문 근거와 함께 추출. 금액은 원문 그대로(1조 8,567억 원 수준)
- Agent ② 해석: 금액 증가가 공모가 확정(밴드 하단 → 상단)과 환율 변경 때문임을 설명해야 함. 삼성 관점에서는 LG가 인도법인 상장으로 대규모 현금을 확보했다는 점과 인도 가전 시장 경쟁 심화 가능성을 다룰 수 있음
- 확인 필요: 매각대금의 사용처(공시에 없음), 상장 후 인도법인의 투자 계획
- 사람 검토: 중요도 "높음" 예상

**확인 포인트**
- [ ] 정정 전·후 금액을 혼동하지 않았는가 (최종 금액은 1,856,757,000,000원)
- [ ] "현금 확보 → 인도 투자 확대" 같은 추론이 사실(FACT)이 아니라 해석·확인 필요로 분리되었는가
- [ ] 과거 사례가 없다는 것을 "과거에 이런 일이 없었다"로 단정하지 않았는가 (수집 범위 부족)

## 사례 3. 애매: 타법인주식및출자증권처분결정 (원공시)

**선정 이유:** 공시 시점에 처분금액, 자기자본대비 비율, 처분예정일이 모두 "-"(미기재)다. 정보가 부족할 때 Agent가 값을 지어내지 않고 확인 필요로 넘기는지 확인한다.

**원문 확인값**

| 항목 | 값 |
|---|---|
| 처분주식수 | 101,815,859주 |
| 처분금액 | `-` (SEBI 승인 전이라 공모가 범위 미확정, "확정 즉시 재공시 예정") |
| 자기자본대비 | `-` |
| 처분예정일 | `-` (SEBI 승인 전 미확정) |
| 처분 후 지분 | 576,956,533주, 85.0% |
| 이사회결의일 | 2025-09-30 |
| 기타 | 2024-12-09 조회공시 답변(미확정)에 대한 확정 공시 |

**기대 결과**
- Program: 처분금액 `CURRENT_VALUE_MISSING`(value=null, triggered=null). "-"를 0으로 바꾸면 안 됨. 과거 사례 없음 + 수집 범위 부족
- Agent ① FACT: 처분주식수, 지분율, 목적, 결의일만 사실로 추출. 처분금액은 "확인 불가"로 분류
- Agent ② 해석: 금액 미정 상태라 규모 판단은 보류. 후속 정정공시를 확인해야 한다고 안내
- 확인 필요: 처분금액, 처분예정일, 공모가 범위
- 사람 검토: 중요도 "보류" 예상 (금액 확정 후 재검토)

**확인 포인트**
- [ ] 보고서 어디에도 구체적인 처분금액(1.7조, 1.8조 등)이 나오지 않는가. 나오면 원문 밖 지식을 끌어온 환각
- [ ] 미기재 항목이 모두 NEEDS_VERIFICATION에 들어갔는가
- [ ] 사례 2와 비교해, 같은 사건인데 정보량 차이를 보고서가 제대로 반영하는가
