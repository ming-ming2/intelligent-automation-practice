# LG전자 OpenDART 실제 수집 데이터

[LG전자_DART_2022-2025.zip](LG전자_DART_2022-2025.zip)은 팀 개발용으로 공유하는 실제 API 수집 결과입니다.
수집일은 2026-10-11이며, 용량은 약 27.3MB입니다. API 키와 `.env`는 포함하지 않습니다.

## 포함 데이터

- 공시 접수 기간: 2022-01-01~2025-12-31
- 공시 유형: A(정기공시), B(주요사항보고), I(거래소공시)
- 공시 목록 153건, 원문 149건, 재무 계정 468개
- 재무 사업연도 2022~2025, 연도별 1분기·반기·3분기·사업보고서
- `data/dart.db`: SQLite DB
- `data/raw/`: 원문 ZIP·XML
- 수집 코드와 기술 안내, 실제 실행 검증 결과

## 사용 방법

1. ZIP을 별도 임시 폴더에 압축 해제합니다.
2. 압축 해제한 `data/` 폴더의 내용을 프로젝트의 `data/`로 복사합니다. 기존 수집 자료가 있다면 먼저 별도로 보관하세요.
3. `data/dart.db`와 `data/raw/`의 상대 경로 구조를 유지합니다.
4. 현재 저장소의 [수집 모듈 안내](../docs/COLLECTOR.md)에 따라 DB와 XML을 읽습니다.

ZIP에 포함된 코드·문서는 수집 당시의 사본입니다. 개발에는 현재 저장소의 코드를 사용하세요.
이미 수집된 DB와 원문을 읽는 데에는 OpenDART API 키가 필요하지 않습니다.

## 제한 사항

거래소공시 4건은 API가 `014`(원문 파일 없음)를 반환하여 원문이 없습니다. 목록과 실패 상태는 DB에 남아 있습니다.
일부 실제 XML에는 엄격한 XML 파싱 오류가 있어 정규화 모듈에서 오류 처리와 내용 대조가 필요합니다.
자세한 내용은 [실제 수집 검증 결과](../results/API_COLLECTION_VALIDATION.md)를 참고하세요.

이 ZIP은 과제용 고정 데이터입니다. 반복 수집 결과를 모두 ZIP으로 커밋하기보다는 필요한 공유본만 갱신하세요.
